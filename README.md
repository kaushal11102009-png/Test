# Mission Test

Mission Test is a teacher-driven test creation and student examination system. This repository now contains the initial app foundation for the Teacher Android app and the Student Web app.

## Status

This is an initial project skeleton created from the provided Mission Test specification. It is not yet a complete production app or verified APK.

## Included

- React + TypeScript + Vite app
- Teacher dashboard skeleton
- Student exam flow skeleton
- Dexie-backed storage layer
- Result code and scoring utilities
- Worker stub
- Build gate and CI workflow skeleton
- Hindi/English language placeholders

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
